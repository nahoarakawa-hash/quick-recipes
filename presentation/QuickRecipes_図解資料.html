Quick Recipes

料理をすばやく作るための、自分専用レシピ Web アプリ。

実物：quick-recipes-opal.vercel.app

1これは何か

紙のレシピ集でやっていた「まとめて・今夜分だけ出して・調理中に見る」を、スマホで続けられるようにしたアプリです。

2解決する面倒・課題

よく作る料理は紙にまとめて、レンジフード横に張って作っていました。便利だった一方で、次の手間が残っていました。

  • 探す 今日の紙をバインダーから抜く。「どのあたりにあったっけ？」
  • 新しく作った料理のレシピを紙に書く 作り方を覚えているうちにレシピ集へ書く手間。
  • また検索する 写す作業をさぼっていると、同じレシピを何度もネットで探し直す。

3作りたいと思った理由

紙のやり方自体は便利で、やめたいわけではありませんでした。

紙を捨てたいのではなく、便利なまとめ方を続けるために、手間をかけないやり方にしたかった。

4実物で見る使い方

毎日の流れは「目次 → 今日セット → 調理」です。

STEP 1目次で探す・絞る
STEP 2今日セットへ集める
STEP 3調理モードで作る

目次

材料名・タイトルで検索。主菜は魚／肉、副菜は和洋中で絞り込み。「今日に追加」で今夜分へ送れます。

今日セット

今夜のレシピだけが並びます。紙の抜き差しなしで、順番の入れ替え・外しもここだけ。

調理モード

大きい文字で材料・手順を表示。タブで品を切替。手順の分数をタップするとタイマーが動き、並行作業も同時に回せます。

レシピの入れ方（要約）：スクショやテキストを貼って下書きを作るか、名前だけ置いてあとから編集。材料・手順を入力して保存します。

5解決できたこと／つくってよかったこと

もともと減らしたかったのは、レシピを探す・紙に書く手間でした。使ってみると、それ以外の効果もありました。

解決できたこと

  • レシピを探す手間・紙に書く手間をなくせた
  • 今夜分だけを手元に集め、紙の抜き差しが不要になった
  • 目線移動が減って調理がスピードアップした
  • 目次で材料を確認し、買い物リストをつくりやすくなった
  • 分類でソートでき、献立作りがしやすくなった
  • タイマーをレシピに組み込み、セットする手間をなくした。複数のタイマーを同時に動かせるようになった

つくってよかったこと

  • 便利だと思っていたやり方の中にも不便があった、と気づけた
  • 自分の献立・調理の流れに合わせたツールを、毎日使える形まで持っていけた

6工夫した点／苦戦した点

工夫した点

  • 献立の考え方に合わせた目次（検索・主菜／副菜の絞り込み）
  • 今夜分だけを「今日セット」に集約
  • 調理中向けの大きい表示と、分数タップのタイマー
  • スクショ／テキスト貼り付けや、名前だけの下書きで登録のハードルを下げる

苦戦した点

  • 色合いをはじめ、見やすく自分好みの UI に仕上げること
  • 細かい操作の詰め（材料・手順の行を自動追加、タイマーの調整や音など）

7技術の概要

Next.js / React / TypeScript / Supabase / Vercel で実装・公開しています。
